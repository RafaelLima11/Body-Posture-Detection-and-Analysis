# Body Posture Detection and Analysis

A Python project that identifies body landmarks and calculates angles and distances between joints.

## Features
- Detect body landmarks
- Calculate angles between body joints
- Measure distances between selected landmarks

## Technologies
- Python
- OpenCV
- CVZone

## How to Run
1. Install the required dependencies.
2. Enable the webcam if required by the script.
3. Run the main Python script.

## Notes
This project demonstrates computer vision and geometric measurements. It is not intended for medical assessment.

## Project Context
Developed as part of a Python programming course.
